## 📖 Descripción

**teris.py** es una implementación básica de Tetris en Python. Mueve y rota piezas (tetrominós) para completar líneas horizontales; cada línea completada desaparece y suma puntos. El juego termina cuando las piezas llegan al tope de la pantalla.

---

## 🚀 Características

- ✔️ Movimiento de piezas con las flechas  
- ✔️ Rotación de piezas  
- ✔️ Caída rápida y modo “drop”  
- ✔️ Sistema de puntuación por líneas completadas  
- ✔️ Interfaz minimalista en consola (sin librerías externas)

---

## 🛠️ Requisitos

- Python 3.6 o superior  
- (Opcional) `curses` si tu plataforma no lo incluye por defecto
